

# 💡 커밋 메시지 템플릿
# ────────────────────────────
# 이모지 라벨명: 무엇을 했는지 요약
# 본문: 선택 (변경 이유, 구현 방식 등)
# ────────────────────────────
# 🏷️ 커밋 태그 정리표
# ───────────────────────────────────────────────
# 📦 Add      : 파일 또는 패키지 추가
# 💡 Chore    : 간단한 기타 작업 (빌드 설정, 환경설정 등)
# 📝 Docs     : 문서 작업 (README, 주석 등)
# ✨ Feat     : 새로운 기능 추가
# 🚨 Fix      : 버그 수정
# 🚀 Perf     : 성능 개선
# 🔨 Refactor : 리팩토링 (기능 변경 없이 구조 개선)
# 🎨 Style    : 스타일 변경 (UI, 파일명, 변수명 등)
# 🗑️ Remove   : 불필요한 코드 및 파일 삭제
# ───────────────────────────────────────────────
# 에러시 "git config commit.template .gitmessage.txt" 입력
